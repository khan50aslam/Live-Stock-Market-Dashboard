# Live-Stock-Market-Dashboard
# 📈 Stock Market Dashboard

A dynamic and interactive **Stock Market Dashboard** built with **Streamlit**, **Plotly**, and **YFinance** to visualize live stock market data.

## 🚀 Project Overview

This dashboard allows users to:
- Fetch **live stock market data** from Yahoo Finance.
- Visualize **Closing Price**, **Trading Volume**, **Moving Averages**, and **Candlestick Charts**.
- Explore **summary statistics** of stock prices over a selected date range.
- Select different companies and date ranges with an intuitive sidebar.

---

## 🛠️ Technologies Used

- **Python 3**
- **Streamlit** (for dashboard building)
- **YFinance** (for live stock data fetching)
- **Plotly** (for beautiful charts)
- **Pandas** (for data processing)
